Privacy policy

Last updated: 25 November 2026

takar-hishab is a private tool operated by the owner of the BarakahWise YouTube channel for that channel only.

What the tool accesses

  • YouTube Data API (youtube.upload, youtube): to upload the owner's own videos, set titles, descriptions, thumbnails and playlists, and arrange the channel home page.
  • Google Drive API (drive.file): only files that this tool itself creates, to store the owner's own audio and PDF study materials. It cannot see any other Drive file.

What is stored and shared

The OAuth token is stored only on the owner's own computer and as an encrypted secret in the owner's private GitHub repository, used solely to run the uploads. No personal data of any other person is collected. Nothing is sold, shared with third parties or used for advertising.

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.
